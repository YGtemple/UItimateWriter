## 这是什么

`ultimate-writing` 是一个**单入口、按需加载**的写作 Skill，把 30+ 个 GitHub 顶级写作方法论收敛进一个仓库。它解决一个非常具体、非常普遍的问题：

> AI 写出来的东西，"通顺，但没人味"——开头像模板，结尾像硬凑，读两行就知道是模型写的。

这个 Skill 不是"调 prompt 让 AI 写得更好一点"，而是一套**成文约束 + 分层自检 + 工程脚本**，从写作前到交付后逐层把关。

它和普通写作 Skill 的区别在于三个字：**不只是"建议"，而是"能检查"**。大多数写作技巧是"感觉上应该这么做"，这个 Skill 把大量规则做成了可以机械执行的清单和脚本——字数有脚本实测，AI 味有脚本扫描，节奏有量化分数。**模型自己审自己，而不是让你当最后一道质检。**

## 为什么需要它

用 AI 写作的人，几乎都卡在同一个地方：

- **质量不稳定**：同一个主题，这次写得还行，下次就翻车。
- **风格不一致**：写出来不像你，或者一眼就看出是 AI。
- **效率低**：每次都要重新教一遍，发出来还要花半小时改。

这个 Skill 把这三件事一次性解决：**内核保证质量下限，文风系统保证风格一致，按需加载保证一次配置永久复用。**

它尤其适合四类人：

| 人群 | 典型需求 |
|---|---|
| **自媒体 / 内容创作者** | 公众号、小红书、知乎、短视频脚本，要流量也要质量 |
| **网文 / 小说作者** | 连载不崩人设、节奏爽点、伏笔回收 |
| **职场人** | 报告、总结、述职、邮件，快速产出专业内容 |
| **学生 / 研究者** | 论文、文献综述、经验贴，严谨可查证 |

## 核心方法论

### 三层去AI味

这是整个 Skill 的灵魂。多数去 AI 味工具只做第一层——换个词、删个套话，结果文章还是"一股 AI 味"。

因为研究已经证明：**即使把 AI 文章的所有禁用词都换掉，仅靠话语结构特征（开头方式、结尾方式、是否留悬念、是否有具体人名数字），仍能以超过 90% 的准确率识别出 AI 写作。** 更进一步，2025-2026 年的检测研究把 AI 痕迹分成五类线索，其中最底层、最难伪装的是认知特征。

所以这个 Skill 分三层清理：

```
第一层 · 表层     词汇、短语、标点、句式
                  看得见的 AI 腔

第二层 · 话语层    怎么开头、怎么结尾、怎么推进、留不留悬念
                  看不见但决定了"读起来像不像人"

第三层 · 认知层    句子长度方差、代词分布、hedge 时机、情绪具体性
                  最底层、最难伪装、也最可靠的信号
```

#### 第一层：表层清理

| 套话类型 | 典型表达 | 处理 |
|---|---|---|
| 开头套路 | "在当今……的时代""随着……的发展""近年来" | 直接删，用具体场景/人物/数据开头 |
| 元话语 | "值得注意的是""需要指出的是""众所周知" | 直接删 |
| 总结套路 | "综上所述""总而言之""归根结底" | 直接删，让最后一段自己说话 |
| 空洞强调 | "具有重要意义""扮演着重要角色""产生了深远影响" | 换成具体事实或删 |
| 虚假过渡 | "首先……其次……最后""一方面……另一方面" | 拆掉，用口语连接或直接顺承 |
| 互联网黑话 | "赋能""抓手""闭环""底层逻辑""颗粒度" | 换成正常人说的话 |
| 浮夸形容词 | "极致""颠覆性""革命性""现象级" | 删或用具体描述替代 |
| 翻译腔 | "作为一个……的人""这使得……能够……""进行讨论" | "作为一个北漂"→"我北漂五年"；"进行讨论"→"讨论" |
| 被动成瘾 | "被认为""被称为""被广泛关注" | 换成主动句 |
| "的的不休" | 连续多个"的"字句叠加 | 拆句，删多余"的" |

#### 第二层：话语层清理

表层词汇全换对了，文章仍可能像 AI。检查这 8 个话语习惯：

1. **结尾点题**——最后一句在解释整篇"说了什么"（"这个故事告诉我们"）。删掉，结尾停在一个画面或决定上。
2. **单轨推进**——全文一条干净的逻辑线，没有离题、犹豫、旁支。人类会跑题、会自我修正、会承认"这个我不确定"。
3. **人造闭环**——开头的问题结尾被完美解决。人类写作经常留线头。
4. **情绪写成生理反应**——"他的心沉了下去""一股暖流涌上心头"。用动作、停顿、没回的消息来传情绪。
5. **氛围开头**——先写天气、心情，第二段才说正事。直接上内容。
6. **无名泛指**——"有研究表明""专家认为"，没有名字没有数字。要么给来源，要么删。
7. **没有读者**——全文像对空气说话。偶尔直接对读者说"你有没有过这种时候"。
8. **批量趋同**——多篇文章开头、结构、结尾都一样。每篇换一个策略。

> ⚠️ 话语层规则不适用于法律合同、合规文件、技术文档、政府公文——那些文体需要明确、闭环、单轨，那是规范不是 AI 味。

#### 第三层：认知层清理

最底层、最难伪装、也最可靠。

**① 句子长度方差（Burstiness）——最可靠的机械信号**

| 指标 | 人类写作 | AI 写作 |
|---|---|---|
| Burstiness 分数 | 0.6 - 1.2（长短剧烈交替） | 0.2 - 0.4（长度高度均匀） |

AI 为什么均匀？因为它逐 token 取概率最高的续写，天然倾向"回归均值"。人类写嗨了飙出 50 字长句，写急了砸出 3 字短句。这是唯一无法靠"换词"伪装、必须从结构层面重建的信号。`scan_ai.py` 会直接算出这个分数。

**② 代词分布——"我们"滥用、"我/你"缺席**

2025 年的一项语料库研究（100 篇真人评论 vs 100 篇 GPT 评论）发现：真人用"我/你"的频率是 GPT 的**两倍以上**；GPT 重度依赖"我们"制造重复的集体口号（"我们必须……""我们需要……"）。

**③ 情绪具体性缺失**——AI 锚定抽象名词（无力感、焦虑、孤独），人类锚定具体经验、具名例子、时间引用（"上季度""昨天下午两点""我前同事老张"）。

**④ Hedge 悖论**——AI 该确定时也含糊（"可能""或许""在一定程度上"），人类只在真不确定时含糊，确定时直接断言。这种"四平八稳"本身就是最浓的 AI 味。

**⑤ 结构冗余**——AI 段末重述主题句（tell them what you said）。人类段末要么推进新信息，要么干脆停住。

**⑥ 段落间文体变化缺失**——EMNLP 2025 研究发现，人类开头/正文/结尾有不同文体（开头跳、结尾收），AI 从头到尾一个调子。

### 减法优先

80% 的 AI 味靠删就能解决。不编造"人类纹理"来假装真人——**宁可短，不可假**。

### 保护作者声音

改写时保留原文的具体细节、对话、个人经历、独特比喻。不把活的文字压成光滑的摘要。

### 事实零容忍编造

所有数字、日期、人名、引语必须有来源。宁可写"待核实"，不编。

## 九大写作场景

每个场景是一个独立的 mode 文件，按需加载，互不干扰：

| 场景 | 文件 | 核心要求 |
|---|---|---|
| 📱 **公众号长文** | `mode/mode-wechat.md` | 开头 800 字内亮核心，7 种推进方式交替，每 1500-2500 字一个呼吸点 |
| ✍️ **议论文/感悟文** | `mode/mode-essay.md` | 立场鲜明不和稀泥，事实/逻辑/反驳三种论证交替 |
| 📊 **报告/总结** | `mode/mode-report.md` | 结论先行，数据说话，行动项必须有负责人和截止时间 |
| 🎓 **科研论文** | `mode/mode-paper.md` | IMRaD 结构，每个事实有出处，不夸大贡献，不强行去AI味 |
| 🔬 **技术科普** | `mode/mode-tech.md` | 先讲人话再讲逻辑，术语首次出现给定义，类比标注边界 |
| 🛒 **营销/种草文案** | `mode/mode-copy.md` | 卖结果不卖功能，卖点不超过 3 个，有缺点才可信 |
| 🎬 **短视频脚本** | `mode/mode-video.md` | 前 5 秒定生死，口播友好，念出来顺 |
| 📖 **网文小说** | `mode/mode-novel.md` | 每个场景改变局面，重要人物不裸登场，章末留钩子 |
| 🎯 **经验贴** | `mode/mode-experience.md` | 真实第一，方法具体到"用什么、怎么做"，写踩坑 |

## 工作流

写作全程八步，从需求识别到交付自检：

```
① 识别需求      判断写作类型、字数、文风、立场，缺关键参数才追问
② 加载内核      去AI味规则 + 写作铁律 + 自检体系（每次必做）
③ 加载场景      只加载对应的一个 mode 文件，禁止多文件混用
④ 叠加文风      可选，最多加载一个 style 文件
⑤ 加载改写      改写/润色任务加载对应 revise 文件
⑥ 参考模板      需要大纲读 templates/，查禁用词读 references/
⑦ 写作          按模块规范写作，长文分章推进
⑧ 自检          分级自检 + 五维质量门，不通过就改，改到通过再交付
```

## 工具脚本

### 字数统计 `word_count.py`

统计口径与 Word/WPS 一致（中文字符 + 英文单词 + 数字串），可设置上下限自动判定。

```bash
python3 scripts/word_count.py article.md --min 2000 --max 5000
```

输出示例：

```
文件：article.md
中文字符：2384
英文单词：12
数字串数：18
总字数：2414
✅ 字数达标
```

### AI 痕迹扫描 `scan_ai.py`

扫描四类问题：

| 类别 | 内容 | 处理 |
|---|---|---|
| ❌ **严重** | AI 身份声明、拒答话术、客服式结尾 | 命中即不合格 |
| ⚠️ **警告** | 模板化套话、黑话、句式模式 | 建议修改 |
| ⚠️ **占位符** | TODO、待补充、example.com | 建议清理 |
| 📊 **结构层** | 句子长度方差、无名泛指、"我们"滥用、hedge 密度 | 认知特征检测 |

```bash
python3 scripts/scan_ai.py article.md
```

输出示例（结构层部分）：

```
【结构层检查】（认知特征，比词汇更难伪装）

· 句子长度方差（burstiness）：CV = 0.686（12句，平均句长 14.2字）
  → 节奏自然（句子长短有落差，接近人类写作）

· 代词分布：我们×2，我×8，你×3（"我们"密度 2.1/千字）
  ✅ 代词分布正常

· hedge 密度：1.8 次/千字（共 3 处）
  ✅ hedge 密度正常
```

扫描器会直接算出 **burstiness（句子长度方差）** 分数——这是区分人机写作最可靠的机械信号，低于阈值就是"机器节奏"。

## 常见问题

<details>
<summary><strong>Q：装几个 Skill 合适？会互相打架吗？</strong></summary>

反 AI 味 + 一个格式工具 + 有需要再配一个研究向的就够了。装太多，触发描述会互相冲突，你根本预测不了哪条规则会生效。这个 Skill 本身就是"多合一"，一个顶多个。
</details>

<details>
<summary><strong>Q：去 AI 味会不会让文章变成营销号腔？</strong></summary>

不会，而且这是明确禁止的。去 AI 味的目标是"像一个真人写的好文章"，不是"家人们谁懂啊"。内核里专门有一条：从 AI 腔改成营销号腔，是另一种假。
</details>

<details>
<summary><strong>Q：学术论文也要去 AI 味吗？</strong></summary>

不强行去。学术文体本身需要正式、精确、结构化，被动语态和 hedge 是规范不是 AI 味。但套话和空话（"随着……的发展""具有重要的理论和实践意义"）仍然要删。相关规则见 `style/style-academic.md`。
</details>

<details>
<summary><strong>Q：去 AI 味会编造细节来"假装是人"吗？</strong></summary>

绝不。核心铁律是"减法优先"——80% 的 AI 味靠删就能解决，加法必须有真实依据。不编造人名、数据、故事。
</details>

<details>
<summary><strong>Q：能不能模仿某个具体作者的风格？</strong></summary>

可以，走女娲文风系统（`style/style-nuwa.md`），从你提供的样本提取 5 维风格画像再复刻。但只学"怎么写"，不抄袭"写什么"；在世作者风格仅供学习，不用于冒充。
</details>

<details>
<summary><strong>Q：为什么去 AI 味要分三层，只换词不行吗？</strong></summary>

因为研究证明，只换词（表层）几乎没用。检测器即便不看词，仅靠话语结构（怎么开头、怎么结尾、留不留悬念）就能以 90%+ 准确率识别 AI；再往底层，句子长度方差这个纯统计特征，就足以区分人和机器。三层必须一起过。
</details>

<details>
<summary><strong>Q：长篇连载小说能保证不崩人设吗？</strong></summary>

能。小说模式内置了项目文件管理（故事圣经、人物档案、时间线、伏笔台账）和续写协议——续写前必须重读设定和最近章节，禁止凭记忆续写；写后审计检查设定、时间线、因果、伏笔回收。
</details>
