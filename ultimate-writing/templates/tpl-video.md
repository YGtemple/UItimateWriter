# 短视频脚本模板

## 基本信息
- 时长：
- 平台：
- 目标：涨粉/带货/种草/观点输出
- 目标受众：

## 标题/封面文案
[5秒内建立吸引力]

## 脚本正文

| 时间 | 画面 | 口播/台词 | 备注 |
|---|---|---|---|
| 0-5s | [画面描述] | [Hook：话题+抓手+可信度] | 前5秒定生死 |
| 5-15s | | [展开：故事/数据/案例] | 每5-8秒一个信息点 |
| 15-30s | | [核心价值] | 具体细节，不空泛 |
| 30-45s | | [案例/反转/情绪点] | |
| 45-60s | | [行动号召/金句收尾] | 不说"感谢观看" |

## Hook备选（写3-5条选最好的）
1. [晒结果+反转]
2. [数据冲击]
3. [反常识]
4. [痛点+悬念]
5. [金句]

## 口播自检
- [ ] 念一遍绊不绊嘴？
- [ ] 前5秒不看标题能听懂吗？
- [ ] 有没有自问自答的书面句式？
- [ ] 数字是整数吗？
- [ ] 每5-8秒有新信息吗？
- [ ] 结尾有没有废话？
- [ ] 时长和字数匹配吗？（每秒约3-4字）
