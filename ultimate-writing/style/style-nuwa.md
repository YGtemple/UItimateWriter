# 女娲文风提取与复刻

## 定位

当用户提供风格样本（自己的文章、喜欢的作者、品牌文案），要求"模仿这个风格""用我的语气写""像XX那样写"时使用。

核心比喻：女娲造人——用样本（泥）捏出一个风格化身，让后续写作都带着这个风格。

## 第一步：提取风格画像

拿到样本后，从5个维度提取。样本越多越准，最少1篇，建议3-5篇。

### 1. 词汇层
- 高频用词：哪些词反复出现？（不包括"的了是在"等功能词）
- 口头禅/标志性表达：有没有"说白了""讲真""你懂吧"这类个人标记？
- 用词偏好：口语还是书面？通俗还是文雅？爱用动词还是形容词？
- 禁忌词：样本中明显回避什么词？（比如从不用"赋能""抓手"）
- 专业术语密度：每1000字几个术语？术语给不给解释？

### 2. 句法层
- 平均句长：长句为主还是短句为主？
- 长短句比例：是长短交替还是清一色短句/长句？
- 特殊句式：爱用倒装？省略主语？断裂句？反问？排比？
- 标点习惯：破折号多还是逗号多？爱用省略号？分号？
- 开头方式：句子爱以什么开头？（"我""但""其实""你看"……）

### 3. 段落层
- 段落长度：一段几句？多长？
- 开头方式：段落怎么起？（直接陈述？场景？引语？反问？）
- 过渡方式：段落之间怎么转？（"但""再说""有意思的是"还是硬切？）
- 段内逻辑：总分总？层层递进？散点？意识流？

### 4. 修辞层
- 比喻类型：生活化比喻（"像挤牙膏"）还是文学比喻（"像月光碎在水面"）？
- 幽默方式：冷幽默？自嘲？反讽？抖机灵？不幽默？
- 引用习惯：引不引名人名言？引不引数据？引不引身边人的话？
- 感官偏好：偏视觉？听觉？触觉？还是抽象思考为主？

### 5. 声音层
- 叙述人称：我/你/他/我们？
- 与读者距离：面对面聊天？还是俯瞰讲解？还是自言自语？
- 情绪表达方式：直接说"我很生气"？还是用反话？还是冷处理？
- 价值观倾向：样本里反复出现什么态度？（反权威？务实？理想主义？犬儒？）
- 节奏：快还是慢？急促还是从容？

## 第二步：输出风格画像

提取后，用以下格式总结（不展示给用户，自己作为写作依据）：

```
【风格画像】
词汇：[3-5个关键词描述]
句法：[平均句长、标志性句式、标点习惯]
段落：[段落长度、过渡方式]
修辞：[比喻类型、幽默方式]
声音：[人称、距离、情绪、价值观]
标志特征：[2-3个最突出的、一眼能认出的特征]
禁忌：[不能出现什么]
```

## 第三步：按画像写作

写作时：
1. 先按场景模块（mode/）的结构要求搭骨架
2. 再用风格画像调整语言：替换词汇、调整句式、改变节奏、加入标志性表达
3. 场景结构是骨，文风是皮。不要为了模仿风格而破坏结构逻辑。
4. 风格画像中的"标志特征"必须在文中出现至少2-3次，"禁忌"绝对不出现。

## 保真度自检

写完后对照画像检查：
- 词汇层：高频词出现了吗？禁忌词避开了吗？
- 句法层：句长比例对吗？标志性句式用了吗？
- 段落层：段落长度和过渡方式像吗？
- 修辞层：比喻和幽默的类型对吗？
- 声音层：读起来像同一个人写的吗？

**盲测法**：把写出来的一段和样本的一段混在一起，如果能一眼分辨出哪个是AI写的，说明没到位。

## 注意事项

1. **样本优先于规则。** 如果样本的用法和通用写作规则冲突，以样本为准。
2. **不抄袭内容。** 复刻的是风格（怎么写），不是内容（写什么）。不复制样本的具体句子、观点、故事。
3. **风格会漂移。** 长篇写作中每隔几章回看画像，防止逐渐滑回默认AI腔。
4. **样本不足时标注。** 只有1篇短样本时，告诉用户"基于有限样本提取，可能不够准确"，不要假装精准。
5. **在世作者风格仅供学习。** 不用于冒充、不用于商业欺诈、不复制受保护的表达。
