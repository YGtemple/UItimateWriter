# 学术严谨文风

## 定位

学术论文、研究报告、政策分析、文献综述、正式书评。精确、克制、有依据是第一原则。本文风下不强行去AI味——学术文体需要正式和结构化，但套话和空话仍然要删。

## 词汇特征

- 术语精确且全文一致。同一个概念不换说法。
- 用"表明""显示""提示"而非"证明"（除非证据强度确实支持"证明"）。
- 用"关联"而非"导致"，除非研究设计支持因果推断。
- 程度词精确："显著"只在统计显著时用，日常语境用"明显""较大"。
- 避免主观词："有趣的是""令人惊讶的是"——让读者自己判断是否有趣。
- 不用"非常""极其""十分"。

## 句式特征

- 句子可以长，但逻辑必须清晰。一个长句只表达一个逻辑关系。
- 被动语态可接受且常用："受试者被随机分为三组"。
- 时态规范：已有研究用过去时或现在完成时，本研究方法用过去时，普遍真理用现在时。
- 不用反问句、感叹句、省略句。
- 不用"我们可以看到""不难发现"——直接呈现。

## 段落与结构

- 一段一个论点，第一句是主题句。
- 段落内部：主题句→证据→分析→小结/过渡。
- 用标题层级清晰组织。
- 图表有编号和标题，正文引用"如表1所示"。

## 声音

- 第三人称或"本研究"，不用"我"（部分学科允许"我们"，按学科惯例）。
- 与读者保持距离，不讨好、不煽动。
- 承认局限："本研究的样本限于……，结果推广需谨慎。"
- 不确定就说不确定："这一解释尚需进一步验证。"
- 不夸大贡献。

## 学术套话黑名单（这些不是学术规范，是废话）

| 删 | 改成 |
|---|---|
| "随着……的快速发展" | 直接陈述研究背景和问题 |
| "具有重要的理论和实践意义" | 具体说明理论和实践贡献是什么 |
| "国内外学者进行了大量研究" | 引用具体文献说明做了什么 |
| "本文结构如下" | 不需要这一句，直接进入正文 |
| "众所周知""毋庸置疑" | 删，给出处 |
| "在一定程度上" | 说清楚在什么程度上、什么条件下 |
| "由于篇幅所限，不再赘述" | 如果重要就写，不重要就别提 |
| "填补了空白" | 具体说明相对于已有研究推进了什么 |

## 引用规范

- 每个事实性声明有引用。
- 引用格式统一（APA/MLA/GB/T 7714等，按目标期刊要求）。
- 不堆砌引用——引用是为了支撑论点，不是显示读得多。
- 间接引用也要标出处，不把别人的观点写成自己的。
- 直接引用加引号和页码。

## 不同学科微调

| 学科 | 调整 |
|---|---|
| 理工科 | 更短句子、更多被动、公式和图表为主 |
| 人文社科 | 可以更长句、允许阐释性语言、引用经典文本 |
| 医学/生物 | 严格CONSORT/STROBE等报告规范，统计报告完整 |
| 经济学/金融 | 数据和模型为主，表格多，文字解释结果 |

## 禁忌

- 不编造数据或引用。
- 不夸大结论。
- 不使用情绪化或煽动性语言。
- 不写"首次""突破性"除非有确凿证据。
- 不为了"去AI味"而牺牲精确性和正式性。
- 不用emoji、口语词、网络用语。

## 示例对比

AI腔：
> 随着人工智能技术的飞速发展，深度学习在各个领域取得了令人瞩目的成就。众所周知，Transformer架构的出现具有里程碑式的意义，它彻底改变了自然语言处理领域的格局。

学术风：
> Transformer架构（Vaswani et al., 2017）通过自注意力机制实现了并行序列建模，在机器翻译任务上超越了当时主流的循环神经网络模型。此后，基于Transformer的预训练语言模型（Devlin et al., 2019; Brown et al., 2020）在多项NLP基准测试中持续刷新纪录。
