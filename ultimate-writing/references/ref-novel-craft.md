# 小说工艺细节

本文件是 mode-novel.md 的补充，提供更细的叙事工艺指导。写小说遇到具体问题时查阅。

## 一、场景构建

### 场景的最小结构
每个场景包含：
1. **目标**：POV角色在这个场景想要什么（可以很小：喝杯茶、等一个人、问一句话）
2. **冲突**：什么挡住了他（另一个人、环境、他自己的犹豫）
3. **结果**：场景结束时什么变了（信息、关系、处境、情绪）

三个要素缺一个，这个场景就该删或合并。

### 场景进入与退出
- **进入要晚**：不要从角色起床、走路、开门写起。直接切到场景核心已经开始的时刻。
- **退出要早**：冲突结束就切，不要写"然后他们道别、各自回家"。
- 场景之间用硬切（空行或分隔符），不用"与此同时""话说"。

### 场景因果链
场景A的结果必须影响场景B的开局。不是"然后……然后……"，而是"所以……但是……"。

## 二、人物塑造

### 展示人物的四个层次
1. **言行**：他做什么、说什么（最表层）
2. **选择**：在压力下选什么（揭示价值观）
3. **矛盾**：他说的和做的不一致（最真实）
4. **他人反应**：别人怎么对他、怎么说他（侧面）

不要用"他很善良"来展示善良。写他在赶时间时停下来帮了人，同时嘴里在骂。

### 对话的五个功能
每句对话至少完成一个功能：
1. 推进情节
2. 揭示人物
3. 传递信息
4. 制造冲突
5. 建立氛围

只完成"打招呼""寒暄"的对话删掉。

### 对话的潜台词
真人很少直接说心里话。角色说的是A，意思是B，读者要能感受到B。
- "你吃了吗？"可能是"我想你了"。
- "随便。"可能是"你根本不关心我想要什么"。
- 写对话时问自己：这个角色真正想说什么？他为什么不直接说？

### 人物声音差异化
- 不同角色用词不同：大学生说"绝了"，教授说"有意思"，老工人说"扯淡"。
- 句式不同：有人说短句，有人说长句，有人爱反问。
- 去掉对话标签（"他说""她道"）也能分辨谁在说话，才算声音差异化成功。

## 三、视角管理

### 视角类型
- **第一人称**："我"。亲密但受限，只能写"我"知道的。
- **第三人称有限**："他"，但只跟一个角色的感知。最常用。
- **第三人称全知**：什么都知道。容易写散，慎用。
- **多视角**：每章/每场景跟一个角色。必须明确切换，不能在同一场景内跳。

### 视角规则
- 不写POV角色看不到、听不到、不知道的事。
- 不写其他角色的内心（除非全知视角）。只能通过外在表现推测。
- "他不知道，一个巨大的惊喜正在等着他"——这是视角越界，删。
- 不写POV角色自己的面部表情（"他的脸红了"），写感受（"脸上发烫"）。

## 四、时间管理

### 时间跨度
- 重要场景慢放（一个吻写500字）。
- 过渡时间快进（"三天后"一句话带过）。
- 不要均匀分配时间——读者只关心重要时刻。

### 伏笔与回收
- 伏笔要自然：第一次出现时看起来是闲笔，回收时读者才发现"原来那个时候就……"。
- 网文伏笔回收不超过30章，否则读者忘了。
- 伏笔台账记录：埋了什么、在哪章、计划哪章回收、是否已回收。
- 回收时不要解释太多——"还记得第一章那把枪吗？"是败笔。直接开火。

## 五、冲突设计

### 冲突层级
1. **内心冲突**：角色自己的矛盾（责任vs欲望）
2. **人际冲突**：角色之间的对抗
3. **环境冲突**：人与自然、社会、体制的对抗
4. **哲学冲突**：价值观的碰撞

好故事至少有两层同时运作。

### 升级原则
- 冲突不能原地踏步。每一章赌注要更大、选择要更难、代价要更高。
- 如果角色在第10章面临的问题和第3章一样大，读者会走。
- 给角色的选择必须是"两害相权"或"两难"，不是"对vs错"。

## 六、开头与结尾

### 开头三要素
1. 一个人
2. 一个处境
3. 一个问题或异常

不要从世界观介绍、历史背景、天气描写开始。从角色正在做某件事开始。

### 章末钩子类型
- 新信息揭示（"门开了，站在门口的是一个本已死了十年的人。"）
- 危机降临（"手机震了一下，是老板：现在来我办公室。"）
- 反转（"他打开信封，里面是他自己的笔迹。"）
- 决定（"她深吸一口气，按下了删除键。"）
- 悬念问题（"如果他说的是真的，那过去三年的一切都是假的。"）

### 结尾
- 短篇：停在一个有意味的画面或决定上，不解释。
- 长篇：收束主线，留余韵。可以有尾声，但不要把所有人的结局都交代干净。
- 最后一句要能"回响"——读者合上书后还在想。

## 七、节奏与爽点分层

### 黄金三章（开篇留住人）

网文前三章决定生死，读者的耐心只有 300 字：

- **第 1 章**：300 字内必须有钩子——悬念、冲突、金手指亮相，三选一。抛危机，拒绝大段世界观/环境铺垫。
- **第 2 章**：核心矛盾确立，读者要知道这本书要讲什么。
- **第 3 章**：第一个小高潮，明确爽点，让读者觉得"这书能看"。

开篇三步闭环：**困境 → 机遇 → 爽点**。走完这个闭环，跳出率骤降。

### 3-5-10 节奏法则

固定节奏喂情绪，是维持追读的核心：

- **每 3-5 章**：小型爽点——小打脸、小收获、小危机化解。给即时反馈。
- **每 10 章左右**：中型反转——反派算计落空、身份线索曝光、金手指升级。
- **每 20-30 章**：大型高潮——主线阶段突破、势力洗牌、重大恩怨了结。

**节奏红线**：全程流水账无冲突不行，全程高强度打斗无松弛也不行。张弛有度，压抑之后一定要释放——虐十章就要安排一次情绪爆发。

### 情绪值曲线

拆解爆款时，把情节节点抽出来，配上 -9 到 +9 的情绪值，情绪起伏就变成了一组数据：

- 爽点前先压抑（情绪压到负值），反转后拉到峰值（正值）。
- 全程高能 = 全程无感。真正的爽是"先抑后扬"的情绪落差。
- 复合情绪更耐看：治愈中穿插打脸，热血里夹杂温情，避免单一情绪审美疲劳。

## 八、反转与悬念设计

### 反转四招

1. **逻辑误导法**：让读者自己骗自己。先给合理假象，再揭真实动机。所有行为不变，变的是背后的动机。
2. **人设底色置换**：极端错位——让最不可能的人做最不可能的事。先立 A 面，在温暖里埋违和感，高潮揭开 B 面。
3. **多重反转套娃**：假象 → 真相 → 但真相是另一个假象的掩护。每层之间留空间让读者消化，最终反转要解释前面所有不合理。
4. **信息差反转**：翻盘手段必须是前文埋过的伏笔。

**铁律**：没有伏笔的反转叫"强行降智"，有伏笔的反转才是"烟花"。养成伏笔清单。

### 俄罗斯套娃式悬念（长线挖坑）

- **表层悬念**：当下危机如何化解（短期钩子）。
- **中层悬念**：主角身世、金手指来源（中期钩子）。
- **终极悬念**：世界真相、最终敌人、主角终极归宿（长线钩子）。

伏笔浅埋快收——前期出现的道具、人物、对话，尽量在读者遗忘前（网文约 30 章）完成闭环，不让读者产生"作者挖坑不填"的反感。

## 九、画面感与高潮技法

### 开头五法

1. **抛出说不通的画面**：解释是悬念的天敌，先亮画面再慢慢揭。
2. **用反差制造"怎么可能"**：身份和行为错位，反差越大越抓人。
3. **跳过铺垫**：第一句就进入冲突。
4. **第一句亮世界观**：用习以为常的语气说极其荒诞的事，越平静越震撼。
5. **第一段让读者血压上来**：写不公，不是写惨。付出和回报的落差越大越好。

### 高潮六招

1. **多线汇聚**：至少三条线同时推进，最后同时引爆。
2. **极限压抑**：先让主角把苦吃透，堵死所有正常反驳的路，情绪弹簧压到底。
3. **多重 buff 叠加**：时间压力 + 自身限制 + 社会压力，同时压下来。
4. **信息差反转**：翻盘手段必须是前文埋过的伏笔。
5. **侧面烘托**：写围观群众的反应，别光写主角。
6. **情绪余韵**：打完别急着收工，地位反差 + 温情余韵收尾。

### 画面感四法

1. **模糊词换成具体画面**：颜色、材质、形状。写完回头找形容词，换成名词和细节。
2. **远景 → 中景 → 特写**：像导演拍电影一样推镜头。
3. **短句制造冲击**：铺垫用长句，转折高潮换短句。长句拉弓，短句放箭。删"的、了、着"。
4. **至少两种感官**：触觉和嗅觉最容易被忽略，也最能建立代入感。

## 十、修改清单

写完一章后检查：
- [ ] 场景有目标、冲突、结果吗？
- [ ] 进入够晚、退出够早吗？
- [ ] 有没有"他不知道的是"之类的视角越界？
- [ ] 每句对话都有功能吗？
- [ ] 情绪是展示的还是告知的？
- [ ] 章末有钩子吗？
- [ ] 有没有可以删掉的场景/段落/句子？
- [ ] 和前文设定矛盾吗？
- [ ] 时间线对吗？
- [ ] 伏笔有记录吗？
