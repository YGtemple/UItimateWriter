# 选题与标题方法论

本文件是所有"要传播、要流量"的写作（公众号、小红书、短视频、知乎、文案）的必备参考。核心一句话：**选题定生死，标题定点击，内容定留存。**

写之前先想清楚：这篇文章值不值得写？给谁看？他能得到什么？想不清楚，写得再好也没人看。

---

## 一、选题：先问三个问题

动笔前，用这三个问题卡一遍选题：

1. **用户关心吗？** 这个话题是不是他真实的困惑、焦虑、好奇？（不是"我觉得有意思"）
2. **有新意吗？** 有没有新的信息、新的角度、新的方法？（不是别人说烂的）
3. **有落点吗？** 读完能不能带走点什么——一个方法、一个认知、一次情绪释放？（不是自嗨日记）

三个有一个答不上来，这个选题就该换。

## 二、选题的四个价值锚点

用户点开、读完、转发的底层动机，逃不出这四类价值。选题至少要踩中一个：

| 价值类型 | 满足什么 | 适配内容 |
|---|---|---|
| **情绪价值** | 治愈、共鸣、解压、爽感 | 情感、生活感悟、故事 |
| **实用价值** | 技巧、方法、避坑、省钱 | 教程、攻略、干货、测评 |
| **认知价值** | 思维刷新、行业拆解、认知升级 | 深度分析、商业洞察、知识付费 |
| **社交价值** | 话题热议、观点讨论、圈层共鸣 | 公共议题、观点文、时评 |

**关键提醒**：情绪价值最难变现，实用价值最容易变现。做个人 IP 或带货，优先实用价值；做流量和涨粉，情绪价值更猛。爆款往往是"情绪价值 + 实用价值"的交集——既戳中情绪，又给点东西。

## 三、爆款选题公式

```
爆款选题 = 精准人群 + 高频痛点/反常识冲突 + 具体场景 + 落地价值 + 预期反差
```

五要素拆解：

1. **精准人群**：不是"年轻人"，是"30岁被裁的程序员""双非考研的二战党""全职带娃的宝妈"。人群越具体，越戳得准。
2. **高频痛点/反常识冲突**：要么直击他长期存在的焦虑，要么颠覆他的固有认知。
3. **具体场景**：锚定他日常真实发生的场景，不写抽象概念（"加班到凌晨两点"胜过"职场压力大"）。
4. **落地价值**：可感知的收益——增收、避坑、省时、提技、解压、涨认知。
5. **预期反差**：打破预期，制造认知盲区和好奇。

## 四、五类高打开率选题

1. **热点借势**：热点事件 + 自身领域。公式："XX事件 + 我的专业视角"。避坑：不蹭负面热点（明星塌房），除非与领域强相关。
2. **痛点挖掘**：用户喊"疼"的地方就是流量入口。痛点从哪来？**评论区高频提问、客服反馈、私信问题**。
3. **稀缺价值**：别人没说透的——行业内幕、冷门知识、独家经验。"教培机构'转课'套路大揭秘"比"如何选培训班"有吸引力。
4. **情绪共鸣**：让用户觉得"这说的就是我"。爽点（逆袭）、痛点（打工人凌晨12点）、泪点（父母藏起来的爱）。
5. **实用干货**："收藏=学会"的内容最保值。模板："XX（场景）必看！N 个 XX（类型）技巧，亲测有效"。

## 五、选题的六个反常识提醒

1. **评论比点赞重要。** 刷对标账号时，重点看评论区——那里全是用户真实的需求和困惑。
2. **不要认为"别人已经说过了"。** 同一个话题，换人群、换场景、换角度、换深度，就是新选题。一个人的需求就是一类人的需求。
3. **利他，不要自嗨。** 多说"怎么做"，少说"我多牛"。用户只关心自己能得到什么。
4. **争议自带流量。** 但要点是"选择任一观点，自圆其说"，不是和稀泥。有槽点/话题点即有流量。
5. **爆过的选题，换角度再做一遍。** 模仿爆款的结构和选题逻辑，不抄内容。
6. **垂直比爆款重要。** 账号标签乱了，算法推流就不准。持续垂直输出，比偶尔一篇爆款更值钱。

## 六、标题：3 秒决定点击率

用户给标题的时间不到 3 秒。标题不是文章的总结，是**钩子**——它唯一的工作是让人点进来。

### 标题公式（六类，选一个，不要套模板）

| 类型 | 公式 | 示例 |
|---|---|---|
| **数字+利益** | 数字 + 方法 + 结果承诺 | "3 个习惯，让我戒掉内耗" |
| **反差/悬念** | 看似矛盾的两个元素 | "为什么越努力的人，反而越穷？" |
| **痛点提问** | 直接戳痛处的问句 | "写了半年公众号没流量，问题出在哪？" |
| **标签+人群** | 精准人群 + 专属问题 | "30岁职场妈妈：如何平衡副业与家庭？" |
| **民生共情** | 普通人 + 共鸣场景 | "80后最煎熬的一年，上有老下有小" |
| **好奇缺口** | 半句 + 省略，勾人点开 | "我把 XX 和 XX 一起用了一个月，结果……" |

### 标题写作要求

1. **直白、带痛点、有悬念。** 少写文艺晦涩的标题——用户没耐心猜。
2. **一个标题只主打一个点。** 想同时塞数字、痛点、悬念、人群，反而四不像。
3. **数字要具体。** 用"3 个"不用"几个"；用"月薪 3000 到 1 万"不用"收入翻倍"。
4. **可以写多个备选。** 一次出 3-5 个不同公式的标题，挑最戳人的，或交给用户选。

### 标题避雷

- ❌ 太文艺、太抽象、太官方（"浅谈文案写作"）
- ❌ 违规夸大（"根治""100%""特效""绝对"）
- ❌ 太短无信息、太模糊无情绪
- ❌ 标题党：标题承诺的和内容不符，点进来就关，掉信任

---

## 七、选题 + 标题的配合

选题决定"写什么"，标题决定"怎么让人点进来"。两者要一致：

- 选题踩中"情绪价值"，标题就往共鸣、痛点、悬念上靠。
- 选题踩中"实用价值"，标题就往数字、利益、干货上靠。
- 选题有"预期反差"，标题就把这个反差亮出来。

标题和内容不能两张皮。标题党能骗来一次点击，骗不来关注和转发。

## 自检清单

- [ ] 选题踩中了四个价值锚点里的至少一个吗？
- [ ] 目标人群够具体吗？（不是泛泛的"年轻人"）
- [ ] 有没有新信息、新角度，还是别人说烂的？
- [ ] 读完能带走什么？（方法/认知/情绪）
- [ ] 标题 3 秒内能让人停下来吗？
- [ ] 标题直白吗？还是文艺晦涩让人猜？
- [ ] 标题和内容一致吗？有没有标题党？
- [ ] 出了多个标题备选吗？
