# 议论文/感悟文模式

## 定位

观点文、时评、读后感、人生感悟、杂文。核心是"我有一个判断，我来说服你"。不是学术论文，不需要文献综述，但需要论证。

## 字数

- 短篇感悟：800-2000字
- 标准议论文：2000-5000字
- 深度评论：5000-10000字

## 结构

### 开头（10%）
- 从一个具体事件、场景、问题切入，不从"在当今社会"切入。
- 第一段结束前亮出你的核心判断。不要让读者猜你站哪边。

### 论证（70%）
三种论证方式交替：
1. **事实论证**：用具体案例、数据、事件说话。一个好例子胜过三段抽象推理。
2. **逻辑论证**：因果链推演。A导致B，B导致C，但D被忽略了。
3. **反驳论证**：先立靶子（反方最有力的论点是什么），再反驳。这比自说自话有说服力得多。

论证段落结构：论点→论据→分析→小结。但不要每段都用这个结构，变化节奏。

### 结尾（20%）
- 回扣开头的事件或判断。
- 升华要克制：可以指出更深层的问题，但不要喊"让我们一起……"。
- 可以留一个让读者自己想的问题。

## 写作要求

1. **立场鲜明。** 不写"一方面有道理，另一方面也有道理"的和稀泥文章。你可以承认复杂性，但必须有一个最终判断。
2. **论据具体。** "很多人都有这种感觉"不是论据。"我采访了3个人，他们都说……"或"某调查显示67%的……"才是。
3. **不稻草人。** 反驳反方时，用反方最强的论点，不打空气靶。
4. **情感真诚。** 感悟文最忌假大空。写你真正相信的东西，用你真正经历过的细节。
5. **避免鸡汤。** "只要努力就会成功"不是感悟，是偷懒。真正的感悟往往包含矛盾、挣扎和不确定。
6. **可以有刺。** 好的议论文让人不舒服。不要为了"客观"而磨平棱角。

## 常见问题

- **只有观点没有论证**：全文都在说"我认为XX很重要"，但没说为什么、凭什么。
- **只有情绪没有逻辑**：全文都在骂，但没说清问题出在哪、怎么造成的。
- **例子和论点脱节**：例子很精彩但说明不了论点。
- **升华过猛**：前面讲一件小事，结尾突然上升到人类命运。
- **正确的废话**："我们应该用辩证的眼光看问题"——这句话什么都没说。

## 自检额外项

- [ ] 核心判断在前三段亮明了吗？
- [ ] 每个论点都有具体论据支撑吗？
- [ ] 有没有反驳反方最强的论点？
- [ ] 结尾的升华和前面的论证匹配吗？
- [ ] 有没有"正确的废话"段落可以删？
