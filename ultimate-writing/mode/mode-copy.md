# 营销/种草文案模式

## 定位

种草文案、带货文、产品介绍、广告文案、小红书笔记、朋友圈卖货。核心是"让读者想要"，不是"让读者知道"。

## 核心原则

1. **卖结果不卖功能。** 读者不关心你的产品有什么功能，关心用了之后自己能变成什么样。
2. **具体胜过形容词。** "一抹化水"胜过"质地轻盈"；"用了两周，痘印淡到不用遮瑕"胜过"效果显著"。
3. **真诚>套路。** 读者对硬广有免疫力。真实的使用感受、缺点、适用边界比完美吹捧更可信。
4. **先有注意力再有转化。** 标题和前3句决定生死。

## 结构

### AIDA 变体（适合长文案）
1. **Attention（注意）**：一个痛点、一个反常识、一个场景
2. **Interest（兴趣）**：为什么会这样？背后的原因/故事
3. **Desire（欲望）**：用了之后的改变，具体场景描写
4. **Action（行动）**：明确告诉读者下一步做什么

### 小红书笔记结构（适合短文案）
- 标题：数字+痛点+结果（"3个月瘦了20斤，这5个习惯最有用"）
- 开头：个人经历或痛点共鸣（1-2句）
- 正文：分点，每点一个具体方法/产品+使用感受
- 结尾：总结+互动引导
- 标签：5-10个相关话题标签

## 写作要求

1. **标题公式（选一个，不要套模板）：**
   - 数字锚点："月入3000和月入3万的人，区别就在这3个习惯"
   - 反常识："别再每天敷面膜了，皮肤科朋友告诉我……"
   - 身份认同："i人必看：不用社交也能拓展人脉的5个方法"
   - 痛点直击："为什么你涂防晒还是黑了？90%的人都做错了这一步"
   - 好奇心缺口："我把XX和XX一起用了一个月，结果……"

2. **卖点不超过3个。** 什么都讲等于什么都没讲。挑最打动人的2-3个卖点写透。

3. **有缺点才可信。** "这个色号对黄黑皮不太友好，但白皮涂了真的绝"比全是夸的可信。

4. **场景化描写。** 不写"这个保温杯保温效果好"，写"早上8点倒的开水，下午6点喝还烫嘴"。

5. **行动号召要具体。** "点击下方链接"不如"现在下单立减30，前100名送替换装"。

6. **不编造使用体验。** 没有用过的产品不写"我用了"。可以写参数、成分、第三方评测，但不伪造个人经历。

## 不同平台差异

| 平台 | 字数 | 语气 | 特点 |
|---|---|---|---|
| 小红书 | 300-1000 | 闺蜜分享 | emoji、分点、真实感、标签 |
| 朋友圈 | 100-300 | 朋友推荐 | 软、不硬广、配图 |
| 公众号带货 | 1000-3000 | 故事+种草 | 痛点故事→产品→使用感受→优惠 |
| 抖音文案 | 50-200 | 直接有力 | 前3秒hook、口语化、紧迫感 |
| 淘宝详情 | 500-2000 | 专业+利益 | 参数+卖点+场景+信任背书 |

## 自检额外项

- [ ] 标题能不能让人停下来？
- [ ] 前3句有没有建立痛点或好奇？
- [ ] 卖点是"结果"还是"功能"？
- [ ] 有没有具体的使用场景和数字？
- [ ] 有没有写缺点或适用边界？
- [ ] 行动号召具体吗？
- [ ] 读起来像朋友推荐还是像广告？
