# 科研论文模式

## 定位

学术论文、文献综述、研究报告。严谨、精确、可验证是第一优先级。本模式下不强行去AI味——学术文体本身需要正式和结构化，但套话和空话仍然要删。

## 核心原则

1. **每个事实性声明有出处。** 不写"有研究表明"而不引文献。
2. **区分事实与推论。** 数据是数据，你的解释是解释。
3. **不夸大贡献。** "首次提出""填补空白"需要确凿的文献检索支撑。
4. **精确到可复现。** 方法部分写到别人能重复你的实验。

## 结构（IMRaD）

### 标题
- 包含研究对象、方法、核心发现/变量关系。
- 好标题："基于Transformer的中文医学命名实体识别：多中心验证研究"
- 差标题："关于人工智能在医学领域应用的研究"

### 摘要（150-300字）
四句话结构：背景与问题→方法→结果→结论。写完正文最后写摘要。

### 引言
1. 研究领域和重要性（2-3段）
2. 已有研究做了什么、不足是什么（文献综述，按主题组织不按时间罗列）
3. 本研究要解决什么问题、怎么做、贡献是什么
4. 最后一段明确列出研究问题或假设

### 方法
- 研究设计、数据来源与样本、变量定义、分析方法、工具。
- 精确到可复现。用什么软件什么版本、什么统计方法、显著性水平。
- 伦理审查信息（如涉及人类受试者）。

### 结果
- 按研究问题组织，不按分析顺序流水账。
- 表格和图要能自解释（标题、注释完整）。
- 报告效应量和置信区间，不只报告p值。
- 不在这里解释结果的含义，解释放讨论。

### 讨论
1. 复述核心发现（1段）
2. 与已有文献对比：一致/不一致，为什么
3. 理论和实践意义
4. 局限性（诚实写，不走过场）
5. 未来研究方向

### 结论
1段，不重复摘要，讲清这篇论文到底贡献了什么。

## 写作要求

1. **术语一致。** 同一个概念全文用同一个术语，不换说法。
2. **时态正确。** 已有研究用过去时或现在完成时，本研究方法用过去时，普遍真理用现在时。
3. **被动语态可接受。** 学术写作中"实验被分为三组"是规范的，不需要强行改主动。
4. **不堆砌文献。** 引用是为了支撑论点，不是为了显示读得多。
5. **图表不重复正文。** 正文指出关键发现，细节在图表里。
6. **避免因果过度推断。** 相关性不等于因果性，用"关联"而非"导致"，除非研究设计支持因果推断。

## 文献综述要点

- 按主题/论点组织，不按时间罗列（"张三2020年发现……李四2021年指出……"）。
- 综合而非摘要：多篇研究共同说明了什么、分歧在哪里、空白是什么。
- 引用经典文献和最新文献都要有。

## 自检额外项

- [ ] 每个事实性声明都有引用吗？
- [ ] 研究问题在引言末尾明确了吗？
- [ ] 方法部分能让别人重复实验吗？
- [ ] 结果和讨论分开了吗？
- [ ] 局限性是诚实具体的还是走过场？
- [ ] 有没有"首次""填补空白"等夸大表述？有依据吗？
- [ ] 参考文献格式统一吗？
