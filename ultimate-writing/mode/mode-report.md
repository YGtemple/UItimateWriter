# 报告/总结模式

## 定位

工作报告、项目总结、会议纪要、调研报行、述职报告。读者是领导、客户或同事，他们要快速找到结论和行动项。

## 核心原则

**结论先行。** 第一段就给结论，不要铺垫半天才说重点。领导看报告的顺序是：标题→结论→关键数据→行动项。过程和论证放在后面。

## 结构

### 1. 标题
- 好标题："Q3用户增长23%，但留存下降4个百分点——Q3运营总结及Q4计划"
- 差标题："2026年第三季度运营工作总结"

### 2. 摘要/核心结论（开头）
3-5句话说清：做了什么、结果如何、问题是什么、下一步怎么办。

### 3. 正文
按逻辑组织，不按时间流水账：
- **成果**：用数据说话，对比目标和同期。关键数字加粗。
- **问题**：直面问题，不回避。每个问题附带原因分析。
- **分析**：为什么会有这些结果和问题。
- **计划**：下一步做什么、谁来做、什么时候完成。

### 4. 行动项（结尾）
表格形式：

| 事项 | 负责人 | 截止时间 | 预期结果 |
|---|---|---|---|
| XX | 张三 | 10月15日 | XX上线 |

## 写作要求

1. **数据说话。** "效果显著"不是结论，"转化率从2.1%提升到3.4%"才是。
2. **不回避问题。** 报喜不报忧的报告没有价值。问题写清楚，原因分析到位。
3. **删空话套话。** "在领导的正确带领下""圆满完成了各项任务""有力推进了"——全删。
4. **一页纸原则。** 能一页说清的不写两页。用表格、列表代替长段落。
5. **行动项必须可执行。** "加强用户运营"不是行动项，"10月15日前上线新用户7日引导流程，目标次日留存提升5%"才是。
6. **区分事实和判断。** 数据是事实，原因分析是判断，不要混在一起。

## 不同类型报告的侧重

| 类型 | 侧重 |
|---|---|
| 周报/月报 | 进展、阻塞、下周计划。简洁，列表为主 |
| 项目总结 | 目标达成情况、经验教训、可复用的方法论 |
| 调研报告 | 调研方法、核心发现、建议（建议要有依据） |
| 述职报告 | 成果量化、能力成长、不足与改进、下阶段目标 |
| 会议纪要 | 决议、行动项、负责人、截止时间。不记讨论过程 |

## 自检额外项

- [ ] 第一段有没有给结论？
- [ ] 所有成果都有数据支撑吗？
- [ ] 有没有"有力推进""圆满完成"等空话？
- [ ] 行动项有负责人和截止时间吗？
- [ ] 能不能删掉三分之一而不丢信息？
