# 短视频脚本模式

## 定位

抖音/快手/视频号/小红书短视频口播文案、剧情脚本、直播话术。核心是"前5秒不划走，最后给一个行动理由"。

## 核心原则

1. **开头是试用装。** 前5秒必须独立建立吸引力，不假设用户看了标题和封面。
2. **好开头 = 话题 + Hook + 可信度。** "我去年涨粉200万，靠的就是搞清楚选题和标题的区别"——话题（选题和标题）+ Hook（200万粉）+ 可信度（我做到了）。
3. **制造悬念不给答案。** "善良的李亚鹏，认识半个娱乐圈，30年为什么赚不到钱"比"李亚鹏30年干黄十几个项目证明人脉不等于赚钱"好。
4. **口播友好。** 写出来的句子要能一口气念出来。自问自答、书面语、长从句都是坑。

## 时长与字数

| 时长 | 字数 | 节奏 |
|---|---|---|
| 15-30秒 | 50-100字 | 一个观点，一句hook+一个论据+一句收尾 |
| 30-60秒 | 100-200字 | 一个观点+2-3个论据/案例 |
| 1-3分钟 | 200-600字 | 故事+观点+案例+行动号召 |
| 3-5分钟 | 600-1000字 | 完整叙事，有起伏 |

## 结构

### 前5秒：Hook
从以下类型选一个：
- **晒结果+反转**："我发了1万条推文，很多人问我执行力怎么这么强，其实我只是搞清楚了一件事"
- **数据冲击**："80亿、400栋楼、13000套房——"
- **反差**："从攒首付到管理80亿"
- **金句**："不能持有10年，就不要持有10分钟"
- **痛点+悬念**："研究3个月，焦虑3年，后悔30年"
- **反常识**："你以为你在自律？其实你只是在逃避执行"（注意：改成直接陈述更口播友好："只要你没在执行，你的动作大概率就是为了逃避执行"）

### 5-20秒：展开
- 给一个故事、一组数据、一个案例。
- 每5-8秒一个信息点，不要在一个点上停留太久。
- 用"你"而不是"大家""用户"。

### 20-45秒：核心价值
- 讲清楚你要传递的核心信息。
- 有具体细节，不是空泛道理。

### 结尾：行动号召/金句收尾
- 行动号召："关注我，下期讲XX""评论区告诉我你的想法"
- 金句收尾：一句让人想截图的话
- 不要说"感谢观看""记得点赞关注"——用内容本身让人想关注。

## 写作要求

1. **念出来测试。** 写完念一遍，绊嘴的地方就改。念不出口的句子就是坏句子。
2. **一句一意。** 一句话只说一件事。书面语可以写复合句，口语不行。
3. **用"你"。** "你有没有过这种时候"比"很多人都会"有代入感。
4. **数字要整。** 口播用"300万"不用"3,247,891"，用"三分之一"不用"33.3%"。
5. **少用书面连接词。** "然而""此外""因此"换成"但""而且""所以"或直接不用。
6. **允许重复。** 口播中关键词可以重复2-3次，这是口语的特点不是bug。
7. **停顿用换行。** 每句话一行，需要停顿的地方空一行。

## 剧情脚本额外要求

- 3秒内建立人物和冲突。
- 每15秒一个小转折或笑点。
- 人物说话要符合身份，不要所有人都一个腔调。
- 画面描述和台词分开写。

## 自检额外项

- [ ] 前5秒有没有Hook？不看标题能听懂吗？
- [ ] 全文念一遍有没有绊嘴的句子？
- [ ] 有没有自问自答的书面句式？
- [ ] 有没有直接给答案而不是留悬念？
- [ ] 每5-8秒有没有新信息点？
- [ ] 结尾有没有"感谢观看"之类的废话？
- [ ] 时长和字数匹配吗？
