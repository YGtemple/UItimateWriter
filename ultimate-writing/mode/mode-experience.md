# 经验贴模式

## 定位

考研/考公/上岸/求职/留学/转行/学习方法等个人经验分享。读者正在经历同样的事，他们要的是"可复制的方法"和"我也能行"的信心。

## 核心原则

1. **真实第一。** 不夸大、不制造焦虑、不装大神。读者能分辨什么是真经验什么是割韭菜。
2. **可操作。** "要认真复习"不是经验，"每天早上8点到图书馆，先做1小时数学再背1小时单词"才是。
3. **有细节才有说服力。** 用了什么书、什么课、什么方法、每天怎么安排、走了什么弯路。
4. **承认运气和局限。** "我这个方法可能不适合所有人""我基础比较好，所以……"比"跟着我做必上岸"可信。

## 结构

### 开头
- 直接亮结果："双非三跨，4个月上岸985新传，总分392。"
- 或亮痛点："去年这个时候我还在焦虑到失眠，觉得自己肯定考不上。"
- 不要写"随着考研越来越卷……"。

### 背景交代（简短）
- 你的基础、起点、备考时长、每天学习时间。
- 这很重要——读者需要判断你的经验是否适用于自己。

### 干货主体
按阶段或科目组织，每个部分包含：
- **用了什么**：具体书名、课程名、工具名（不编造，不确定的标注"我当时用的是XX，现在可能有更好的"）
- **怎么做的**：具体方法、时间安排、笔记方式
- **踩了什么坑**：弯路比成功经验更有价值
- **为什么这样做**：简单解释逻辑，让读者能举一反三

### 心态/生活
- 焦虑怎么处理的、崩了怎么办、怎么坚持下来的。
- 不要鸡汤，要具体："我每周日下午放假，什么都不学，打游戏/逛街。"

### 结尾
- 给正在备考的人一句话。
- 可以答疑引导（"有问题评论区问"）。
- 不喊口号。

## 写作要求

1. **时间线清晰。** "3-6月打基础，7-8月强化，9-10月真题，11-12月冲刺"比"前期中期后期"清楚。
2. **数字具体。** "政治78分""英语阅读错2个""每天学10小时"。
3. **不推荐自己没用过的东西。** 没看过的课不推荐，没做过的题不吹。
4. **区分事实和感受。** "这本书我刷了3遍"是事实，"这是最好的书"是感受。
5. **不制造焦虑。** "别人都学12小时我才8小时"——不要写这种。写你自己的节奏。
6. **可以有情绪。** 经验贴不是论文，可以写崩溃、写自我怀疑、写想放弃的时刻。这才是真人。
7. **不写"必看""必上岸""封神"。** 用"对我帮助很大""我觉得适合XX基础的人"。

## 不同平台

| 平台 | 字数 | 特点 |
|---|---|---|
| 知乎 | 3000-8000 | 详细、有逻辑、长文有市场 |
| 小红书 | 800-2000 | 分点、emoji、图片（笔记截图/时间安排表）、标题党 |
| 公众号 | 2000-5000 | 故事感强、有情感共鸣 |
| 贴吧/论坛 | 1000-3000 | 直接、口语化、不端着 |

## 自检额外项

- [ ] 开头有没有亮结果或痛点？
- [ ] 背景交代了吗？读者能判断是否适用吗？
- [ ] 方法具体到"做什么、怎么做、用什么"了吗？
- [ ] 有没有写踩坑/弯路？
- [ ] 有没有夸大或制造焦虑？
- [ ] 推荐的东西都是自己用过的吗？
- [ ] 有没有"必上岸""封神"等绝对化表述？
