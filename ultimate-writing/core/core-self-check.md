# 分级自检体系

定稿前必须执行自检。按严重度从高到低检查，P0/P1不通过不能交付。

## 严重度分级

| 级别 | 含义 | 处理 |
|---|---|---|
| **P0** | 致命问题：编造事实、AI自曝身份、逻辑断裂 | 必须修复，否则不交付 |
| **P1** | 严重问题：结构混乱、核心论点不清、AI套话密集 | 必须修复 |
| **P2** | 明显问题：个别AI句式、翻译腔、段落过长、重复 | 应该修复 |
| **P3** | 优化项：节奏可微调、用词可更精准、个别句子可更短 | 尽量修复 |
| **P4** | 风格偏好：可改可不改，不影响质量 | 不改 |

---

## P0 检查（致命）

- [ ] 有没有编造的数字、日期、人名、引语、事件？
- [ ] 有没有"作为AI""本文由AI生成""我无法访问"等AI身份声明？
- [ ] 有没有前后矛盾的事实或逻辑？
- [ ] 小说：有没有违反已确立设定/时间线/人物关系的地方？
- [ ] 论文：有没有未标注来源的事实性声明？
- [ ] 有没有占位符残留（TODO、XXX、待补充、example.com）？

## P1 检查（严重）

- [ ] 读者在前800字内能知道文章讲什么、为什么值得读吗？
- [ ] 核心论点/主线清晰吗？还是素材堆砌？
- [ ] 有没有大段AI套话（"值得注意的是""综上所述""在当今时代"）？
- [ ] 有没有连续三段以上结构相同的排比段？
- [ ] 结尾在空洞升华或喊口号吗？
- [ ] 每一章/节都在推进吗？有没有可以整段删掉而不影响文章的部分？
- [ ] 改写任务：有没有改变作者的核心观点或事实？
- [ ] 小说：重要人物首次出场有没有锚定信息？场景有没有改变局面？

## P2 检查（明显）

- [ ] 有没有"不是A而是B"的平行否定句？
- [ ] 有没有三段式形容词/名词排比？
- [ ] 破折号是否超过每500字1个？
- [ ] 有没有"这使得……能够……""进行+动词"等翻译腔？
- [ ] 有没有超过40字的长句需要拆？
- [ ] 有没有超过4行的段落需要拆？
- [ ] 有没有连续两段以相同方式开头？
- [ ] 有没有"非常""极其""十分"等无效程度副词？
- [ ] 有没有"赋能""抓手""闭环"等黑话？
- [ ] 对话是否自然？有没有角色在向已知情的人解释背景？
- [ ] 数据有没有翻译成人话？

## P3 检查（优化）

- [ ] 长短句节奏是否有变化？有没有连续5句以上长度相近？
- [ ] 至少30%的段落是否"不完美收尾"（没有总结句）？
- [ ] 有没有具体的人名/数字/日期？（非虚构类必须有）
- [ ] 用词能否更精准、更不那么"概率最高"？
- [ ] 有没有句子以"但""所以"开头制造口语节奏？（可以有）
- [ ] 有没有至少一处作者的真实判断或态度？
- [ ] 小说：情绪是否通过动作/物品/停顿传递，而非直接命名？
- [ ] 小说：有没有1-3个生活质感细节（不是填充，是揭示人物）？

## P4 检查（风格偏好，不强制）

- [ ] 某个词的选择是否可以更好？（但不影响可读性就不改）
- [ ] 某个比喻是否可以更巧妙？（但当前比喻已成立就不改）
- [ ] 段落顺序是否可以调整？（但当前顺序已通顺就不改）

---

## 自检流程

1. **通读全文一遍**，不修改，只标记问题位置。
2. **按P0→P1→P2→P3顺序修复**。P0/P1全部修完再修P2，以此类推。
3. **修完再默读一遍**。绊嘴的句子改，听着像通稿的段落重写。
4. **如果是字数敏感任务**（公众号长文、论文、脚本），运行 `scripts/word_count.py` 确认字数。
5. **如果是去AI味任务**，运行 `scripts/scan_ai.py` 扫描残留AI痕迹。
6. **交付时附自检结果**：字数、发现并修复的主要问题、遗留的P3/P4项（如有）。

## 不同场景的自检侧重

| 场景 | 侧重检查 |
|---|---|
| 公众号长文 | P1开头钩子、P2段落长度、P3节奏变化、配图位置 |
| 报告/总结 | P0数据准确、P1结论清晰、P2套话（"有力推进""圆满完成"） |
| 论文 | P0引用完整、P1论证链、P2学术套话（不强行口语化） |
| 文案 | P1钩子、P2行动号召是否自然、P3用词精准 |
| 短视频脚本 | P1前5秒hook、P2口播友好度（念出来顺不顺）、P3节奏 |
| 小说 | P0设定连贯、P1场景推进、P2情绪展示而非告知、P3生活质感 |
| 改写 | P0观点不变、P1声音保留、P2局部手术而非全文重写 |

## 量化质量门（五维打分）

清单检查之外，再打一轮分。这是把"感觉还行"变成"可判定"的关键一步。

对成品从五个维度各打 1-10 分：

| 维度 | 问什么 | 低分信号 |
|---|---|---|
| **直接** | 是不是开门见山，没有绕弯子和铺垫？ | 大量元话语、开头绕、结论藏在最后 |
| **节奏** | 长短句有没有落差？段落长短有没有变化？ | 句子长度均匀、段落长度雷同 |
| **可信** | 有没有具体的人、数字、时间、场景支撑？ | 空泛断言、"有研究表明"无名泛指 |
| **真诚** | 有没有作者的立场、判断、情绪？是人在说还是机器在汇报？ | 处处 hedge、无立场、无第一人称在场 |
| **密度** | 每句话都携带新信息吗？删得动吗？ | 车轱辘话、重复表达、信息量为零的句子 |

**判定标准：**
- 总分 ≥ 40（满分 50）→ 可以交付
- 35-39 → 勉强，最好补强弱项
- < 35 → 打回重写（重点改得分最低的两个维度）

**打分要诚实。** 这是给自己把关，不是走过场。五个维度里，直接和密度最容易被 AI 拖垮——AI 默认绕弯子、默认注水，这两项低了必须动结构，不是改两个词能解决的。

---

## 自检不是让文章变光滑

自检的目标是"像一个真人写的好文章"，不是"没有任何问题的完美文章"。真人写作有毛刺、有跳跃、有个人习惯。不要把所有不规整都修掉——修掉的可能正是作者的声音。

判断标准：如果一个"问题"同时承载了人物性格、声音、节奏或氛围，它就不是问题，保留。
