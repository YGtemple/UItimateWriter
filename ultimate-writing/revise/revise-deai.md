# 重度去AI重构

## 适用场景

用户说"这篇太AI了""去AI味""像ChatGPT写的""humanize""去味"，或原文AI痕迹非常密集，需要深度重构而非局部修词。

## 工作流

### 第1步：通读原文，不动笔
读一遍，理解：作者想说什么？目标读者是谁？原文的声音是什么（如果有）？哪些内容是有价值的核心，哪些是AI填充？

### 第2步：诊断（按严重度分级）

**P0 致命：**
- AI身份声明（"作为AI助手""本文由AI生成"）
- 编造的事实/数据/引语
- 逻辑断裂、前后矛盾

**P1 严重：**
- 话语层问题：结尾点题、单轨推进、人造闭环、氛围开头、无名泛指
- 大段套话（"在当今时代""值得注意的是""综上所述"）
- 结构是AI模板（总-分-总、每段恰好三点、开头问问题结尾回答）

**P2 明显：**
- "不是A而是B"平行否定
- 三段式排比
- 翻译腔、被动成瘾
- 破折号过多
- 段落整齐收尾

**P3 优化：**
- 长短句节奏均匀
- 用词概率最高、不意外
- 缺少具体细节
- 缺少作者判断

### 第3步：三遍稿重构

**第一遍：砍。**
- 删掉所有P0/P1问题内容。
- 删掉所有套话、元话语、空洞过渡。
- 删掉重复表达（同一个意思换着说三遍的，留一句最好的）。
- 删掉不携带信息的句子。
- 这一遍结束后，文章通常会缩短30-50%。这是正常的。

**第二遍：改。**
- 把抽象改成具体："效果显著"→"转化率从2.1%涨到3.4%"。
- 把书面改成口语（按目标文风）："然而"→"但"，"进行分析"→"分析"。
- 把被动改成主动。
- 把长句拆成短句。
- 把"不是A而是B"改成直接肯定。
- 把三段式排比改成两个或四个。
- 把告知改成展示（叙事文）："他很生气"→"他把杯子搁下，力气大了点，茶溅出来"。
- 修复话语层：换开头（直接上内容）、换结尾（不总结）、加入真实细节（有依据的）、留开放问题。

**第三遍：养。**
- 恢复人类纹理：长短句剧烈交替、偶尔以"但""所以"开头、加入作者真实判断、允许1-2处不完美。
- 但**不编造**。不能凭空加人名、数字、故事。减法优先，加法必须有原文依据或用户提供。
- 检查是否从AI腔改成了营销号腔（"家人们""太炸裂了"）——如果是，改回来。
- 检查是否改得太干太光滑——真人写作有毛刺。

### 第4步：默读
全文念一遍（或默念）。绊嘴的句子改。听着像通稿的段落重写。

### 第5步：输出
默认输出格式：
```
## 诊断
[P0/P1/P2/P3各发现了什么，数量]

## 重构后全文
[完整文章]

## 主要修改点
1. [原文] → [改后]（为什么）
2. ...
（3-6条）

## 遗留说明
[如有不确定的事实、需要用户补充的细节、风格上的可商量之处]
```

用户只要结果时，只输出重构后全文。

## 核心原则

1. **保观点不保句子。** 重度重构可以重写每一句话，但作者的核心论点、立场、事实不能变。
2. **保声音。** 如果原文有个人声音（口头禅、独特比喻、个人经历），保留。没有的话，按目标文风建立。
3. **不编造人类纹理。** 去AI味最大的坑是"假装是人"——加一堆虚构的个人经历和数据。宁可短，不可假。
4. **减法优先于加法。** 80%的AI味靠删就能解决，不要急着加东西。
5. **不要从一种假改成另一种假。** AI腔和营销号腔都是假，目标是真人写作。
