# 高级文笔润色

## 适用场景

用户说"润色一下""文笔提升""改得更好""polish""优化表达"，原文基础不错但文笔有提升空间。不是去AI味（那走 revise-deai），而是让好内容写得更好。

## 核心原则

**润色是打磨，不是重写。** 保留作者的声音、结构和核心表达，只在句子层面提升精准度、节奏和力量感。

**不要把有特点的文字磨光滑。** 有些"不完美"正是作者的声音。粗糙但有力的句子比光滑但平庸的句子好。

## 润色清单

### 1. 精准度
- 模糊词换成精确词："很好"→好在什么地方？"很多"→多少？
- 动词升级："做出了反应"→"拍了桌子"或"沉默了三秒"。
- 删冗余修饰："非常巨大"→"巨大"或直接给数字。
- 歧义词消歧：一句话有两种理解时，改成一种。

### 2. 力度
- 被动改主动："这个决定被大家认为是错的"→"大家觉得这个决定错了"。
- 名词改动词："完成了数据的采集"→"采集了数据"。
- 把弱句尾改成强句尾：句子最后一个词是重点，不要用"了""的""是"收尾。
- 删铺垫："我想说的是""事实上""实际上"——直接说。
- 双重否定改肯定："不是没有道理"→"有道理"或"确实如此"。

### 3. 节奏
- 连续长句中插一个短句。
- 连续短句中偶尔放一个长句铺陈。
- 关键判断单独成段。
- 删掉多余的连接词，让句子之间靠逻辑自然衔接。
- 列表项长度不要完全一样——有长有短更自然。

### 4. 画面感（叙事文）
- 抽象改具象："他生活很拮据"→"他把烟掐灭，留了半截，明天接着抽"。
- 感官细节：视觉之外加听觉、触觉、嗅觉。
- 但细节必须有用——同时完成描写和揭示人物/氛围。
- 不堆细节：一个场景最多3个感官细节。

### 5. 声音一致性
- 全文语气统一吗？有没有突然从口语跳到书面语？
- 同一个人的前后说话方式一致吗？
- 叙述视角有没有漂移？

## 不要做的事

- 不要改变作者的核心观点。
- 不要把作者的个人风格改成"标准好文章"。
- 不要增加原文没有的事实、数据、引语。
- 不要把简洁的文字改冗长。
- 不要每句都改——好句子保留，只改需要改的。
- 不要把口语改成书面语（除非场景要求）。

## 输出格式

```
## 润色后全文
[完整文章]

## 主要修改点
1. [原文] → [改后]（为什么：力度/精准/节奏）
2. ...
（3-8条，只列有代表性的修改，不列每一个逗号的改动）
```

用户只要结果时只输出润色后全文。

## 判断标准

润色完的文章应该满足：作者读了觉得"这就是我想说的，但我说得没这么好"，而不是"这不像我写的"。
