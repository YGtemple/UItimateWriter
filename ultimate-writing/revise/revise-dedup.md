# 去重去同质化

## 适用场景

用户说"重复了""段落雷同""车轱辘话""去重""同质化""每段都差不多"。

## 重复类型

### 1. 词语重复
- 同一个词在相邻句子中反复出现。
- 例："这个方法很有效。有效之处在于……使用这个方法后……"
- **修复**：第二个起用代词、同义词或直接省略。但不要为了避重就用生僻词——重复关键词有时是修辞需要。

### 2. 句式重复
- 连续段落用相同的句式结构。
- 例：连续三段都以"我们需要……"开头；连续三段都是"……是……的"。
- **修复**：改变句式，换开头方式，长短句交替。

### 3. 论点重复
- 同一个观点在不同段落反复出现，没有新进展。
- 例：第2段说"AI写作需要去AI味"，第5段又说"去AI味很重要"，第8段再说"我们必须重视去AI味"。
- **修复**：合并重复论点，只在一个地方讲透。其他地方如果需要提及，用一句话引用而非重新展开。

### 4. 案例重复
- 同一个例子在文中多次使用。
- **修复**：一个例子只用一次，用在最能支撑论点的地方。其他地方换例子或不举例。

### 5. 过渡重复
- 每段都用相同的过渡方式。
- 例：每段开头都是"首先""其次""再次""此外""最后"。
- **修复**：删掉大部分过渡词，靠内容逻辑自然衔接。需要过渡时换方式（反问、转折、具体场景）。

### 6. 结构重复
- 每段都是"观点→解释→例子→小结"的四段式。
- **修复**：变化段落结构。有的段落先给例子再亮观点，有的段落只有例子不解释，有的段落用对话代替论述。

### 7. 信息重复
- 同一个信息用不同的话说了多遍。
- 例："他非常生气。他怒火中烧。他气得不行。"
- **修复**：留一句最好的，删其他。

## 去重流程

1. **通读全文，标记重复点。** 每发现一个重复，标注类型（词语/句式/论点/案例/过渡/结构/信息）。
2. **合并同类项。** 论点重复的合并成一段；案例重复的保留最有力的一个；信息重复的留最精准的一句。
3. **变化表达。** 词语和句式重复的，换说法或换结构。但关键词不强行替换。
4. **检查结构。** 如果每段结构相同，重排部分段落的结构。
5. **通读验证。** 去重后文章是否更紧凑？有没有删掉不该删的（有意的重复修辞，如排比、递进）？

## 有意重复 vs 无意重复

不是所有重复都要删：

- **排比**：有意的重复结构，用于制造节奏和力量。保留。
- **递进**："他来了，他看见了，他征服了"——重复中有推进。保留。
- **呼应**：开头和结尾的呼应。保留。
- **强调**：关键词重复2-3次（尤其口播稿）。保留。
- **车轱辘话**：同一个意思原地打转，没有推进。删。

判断标准：重复是否带来了新东西（新信息、新角度、新节奏、新情绪）？有就留，没有就删。

```
## 去重诊断
| 类型 | 位置 | 处理方式 |
|---|---|---|
| 论点重复 | 第2段与第5段 | 合并到第2段，第5段删除 |
| 句式重复 | 第3-5段开头 | 改变开头方式 |
| ... |

## 去重后全文
[完整文章]

## 主要修改
1. [删了什么/合并了什么/改了什么]
2. ...
```
