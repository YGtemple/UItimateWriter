# 节奏疏密调整

## 适用场景

用户说"节奏不对""太密了读着累""太散了不紧凑""拖沓""仓促""长短句调整""节奏优化"。

## 节奏问题诊断

### 太密（读着喘不过气）
- 连续5句以上长度相近（都是20-30字）。
- 每段都在给信息，没有呼吸点。
- 长句套长句，一个逗号接一个逗号。
- 数据和观点密集轰炸，没有案例或场景缓冲。
- **表现**：读者读完一段记不住任何东西。

### 太散（读着提不起劲）
- 连续短句太多，像电报。
- 段落之间没有推进，原地踏步。
- 太多过渡句、重复句、铺垫句。
- 同一个意思用三种方式说。
- **表现**：读者觉得水，想跳读。

### 节奏单调
- 全文一种速度，没有快慢变化。
- 每段结构相同（总-分-总）。
- 开头和结尾方式雷同。
- **表现**：读着像机器输出，没有情绪起伏。

## 调整方法

### 1. 长短句交替
- 长句（30字以上）铺陈信息、描写场景、推进逻辑。
- 短句（10字以内）砸重点、制造停顿、给情绪。
- 理想节奏：2-3个中长句后跟1个短句。
- 关键判断、转折、金句单独成句甚至单独成段。

### 2. 段落长度变化
- 长段（5-8句）用于深度分析、叙事铺陈。
- 中段（2-4句）用于常规推进。
- 短段（1句）用于强调、转折、钩子。
- 不要连续3段长度相同。

### 3. 呼吸点设置
- 每1000-2000字（长文）或每30秒（口播）插入一个呼吸点：
  - 一个小故事或场景
  - 一句直接引语
  - 一个反问
  - 一个具体数据
  - 一句金句
  - 一个停顿（短段）
- 呼吸点不是水，是让读者消化前面信息的间隙。

### 4. 信息密度调节
- 高密度段（分析、数据）后跟低密度段（故事、场景、感受）。
- 一个复杂概念讲完后，用一个大白话例子翻译一遍。
- 删掉"信息密度为零"的句子（"我们需要认真思考这个问题"——什么也没说）。

### 5. 场景切换
- 长篇中，连续分析/议论不超过2000字，必须切换到：人物、场景、故事、对话。
- 连续叙事不超过2000字，必须切换到：分析、总结、观点。
- 文武之道，一张一弛。

### 6. 开头和结尾节奏
- 开头要快：短句子、快节奏、迅速切入。
- 结尾可以慢：长句铺陈、留白、余韵。
- 但结尾不能拖：最后3段不要再引入新信息。

## 口播稿节奏额外规则

- 每句话不超过20字（口播）。
- 每3-5句话有一个停顿（空行或省略号）。
- 每15秒一个信息点或情绪点。
- 关键词可以重复2-3次（口语特征）。
- 念一遍：哪里念着喘不过气就拆句，哪里念着无聊就删。

## 输出格式

```
## 节奏诊断
- 整体节奏：[太密/太散/单调/基本合理]
- 问题位置：[哪些段落太密/太散/雷同]
- 调整策略：[具体怎么调]

## 调整后全文
[完整文章]

## 主要调整
1. [哪里]：[怎么调的]
2. ...
```

## 注意

- 节奏调整不改变内容和观点，只改变句子和段落的排列方式。
- 作者的标志性长句或短句不要动——那是声音的一部分。
- 不同类型文章节奏不同：报告可以密一些，散文可以松一些，口播必须短平快。
